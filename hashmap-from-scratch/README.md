# HashMap From Scratch

This project builds a small hash map in Java without using the built-in map classes. The example stores student IDs as keys and student names as values.

## What it shows

- How key-value data can be stored in an array.
- How a hash function picks an array index.
- How chaining handles two keys that land at the same index.
- How to add, find, update, remove, and print records.

## Run

```bash
javac -d out src/*.java
java -cp out HashMapDemo
```

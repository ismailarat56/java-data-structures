# Java Data Structures

Small Java examples for basic data structures and recursion. Each folder is a separate project that can be compiled and run on its own.

## Projects

- `stack-from-scratch`: an array based stack for an undo history.
- `queue-from-scratch`: an array based circular queue for a call line.
- `hashmap-from-scratch`: a small hash map with key-value entries and chaining.
- `04-recursion-basics`: simple recursive and iterative method examples.
- `05-tree-basics`: a basic binary tree with traversal examples.

## Run

Open one project folder and follow the commands in its `README.md`.

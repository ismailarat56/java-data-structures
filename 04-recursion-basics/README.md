# Recursion Basics

This project shows simple recursion examples in Java. It compares recursive and loop based solutions for small number problems.

## What it shows

- How a method can call itself.
- Why a recursive method needs a stop case.
- How factorial can be written with recursion or a loop.
- How Fibonacci can be written with recursion or a loop.
- How to print numbers with recursive methods.

## Run

```bash
javac -d out src/*.java
java -cp out RecursionDemo
```

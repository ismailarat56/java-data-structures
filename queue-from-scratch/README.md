# Queue From Scratch

This project builds a small queue in Java without using the built-in queue or list classes. The example stores people waiting for call center service.

## What it shows

- How a queue can use an array.
- How FIFO works: first in, first out.
- How a circular queue moves front and rear positions.
- How to add, remove, peek, and print queue items.

## Run

```bash
javac -d out src/*.java
java -cp out Main
```

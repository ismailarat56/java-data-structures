# Stack From Scratch

This project builds a small stack in Java without using the built-in stack or list classes. The example stores text editor actions and uses undo to remove the last action first.

## What it shows

- How a stack can use an array.
- How LIFO works: last in, first out.
- How to add, remove, peek, and print stack items.
- How to check if the stack is empty or full.

## Run

```bash
javac -d out src/*.java
java -cp out StackDemo
```

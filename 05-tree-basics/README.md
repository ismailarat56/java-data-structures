# Tree Basics

This project builds a small binary tree in Java. It creates nodes from `A` to `F` and prints the tree in different orders.

## What it shows

- What root, node, edge, and leaf mean.
- How a binary tree stores left and right child nodes.
- How to build a tree by linking nodes.
- How preorder, inorder, and postorder traversal work.

## Run

```bash
javac -d out src/*.java
java -cp out Main
```
